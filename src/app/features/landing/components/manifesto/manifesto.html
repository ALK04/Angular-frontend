§ 01 · Le constat

Chaque projet recommence par les mêmes deux heures perdues : init du repo, config Vite, Tailwind, un serveur Express, la structure des dossiers, le routing, un README vide. Le vrai travail n'a même pas commencé.

Sans Calque
  • On copie-colle un ancien projet et on nettoie.
  • On recâble Vite, Tailwind, le serveur, les scripts.
  • On range les dossiers « plus tard », c'est-à-dire jamais.
Avec Calque
  • On choisit ses modules au catalogue, visuellement.
  • On télécharge un dépôt déjà structuré et documenté.
  • npm install, npm run dev, on code.
