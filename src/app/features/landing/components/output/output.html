§ 06 · La livraison

Un dépôt, pas un site verrouillé.

Calque ne vous donne pas un compte ni un hébergement : il vous donne un dossier. Un monorepo TypeScript propre, où chaque chose est à sa place et où le thème que vous avez choisi est déjà écrit.

  1. $ npm install installe client & serveur
  2. $ npm run dev lance les deux d'un coup

À partir de là, c'est votre code. Vous l'ouvrez, vous le modifiez, vous le déployez où vous voulez.
